## How to read the portfolio

Repository documentation separates implemented behavior, measured results, prototype limitations, and source attribution. Reproducible setup and validation evidence matter more than broad performance claims.

BioSentinel's physical replay resistance remains unverified. NexusAI is a non-executing rebuild with unresolved dependency advisories. Job Copilot currently implements resume notes; AI tailoring and job scraping are outside its scope.
